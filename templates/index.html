Under the surface

Built as an end-to-end ML project.

From raw data to a served prediction, the work remains connected and traceable.

A

Data preparation

Student records move through a repeatable ingestion and transformation flow before modelling.

B

Model selection

C

Useful delivery

Project map

What's inside the studio?

Six connected parts take the project from source data to a useful score forecast.

IN

Data ingestion

Loads stud.csv and preserves the raw, train, and test data in the project artifacts.

TX

Data transformation

Scales numerical fields and one-hot encodes categories through a reusable transformer.

ML

Model training

Compares regression models with tuning, then saves the strongest model for predictions.

UI

Flask web app

Delivers a responsive predictor with guided inputs, validation, and a focused result popup.

LG

Logging & errors

Keeps timestamped logging and contextual exceptions close to the underlying ML workflow.

TR

Training workflow

The included training pipeline can regenerate the model artifacts when the data changes.
